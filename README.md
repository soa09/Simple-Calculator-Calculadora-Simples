# 🧮 Calculadora Simples / Simple Calculator

Este repositório contém duas versões de uma calculadora simples desenvolvida em Java — uma em português e outra em inglês — ideal para iniciantes que desejam praticar lógica de programação e operações matemáticas básicas.

This repository contains two versions of a simple calculator built in Java — one in Portuguese and another in English — ideal for beginners who want to practice programming logic and basic math operations.
